What this report can't tell you yet

  • Technical SEO — Core Web Vitals, crawl errors, broken links. Needs PageSpeed Insights / Screaming Frog.
  • Backlink profile — referring domains, authority, toxic links. Needs Ahrefs / SEMrush / Moz.
  • True SERP rank tracking — GSC gives averaged position, not a daily rank per keyword.
  • Competitor benchmark — no comparison source connected yet.
  • On-page content audit — title/meta/heading structure, keyword cannibalization across pages.
